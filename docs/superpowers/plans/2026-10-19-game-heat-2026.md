# 2026 遊戲熱度觀察 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依 `SPEC.md` 做出一個離線單檔 `index.html`（第一人稱走廊＋六間類型房間＋Tab 總計分板），以及產生它的數據流程 `tools/fetch_data.py` → `tools/build_data.py`。

**Architecture:** 數據與畫面分離。`tools/rules.py` 是純函式（排名、分房、留存、門縫光），`build_data.py` 讀 `data/` 產生 `data/site_data.json` 並注入 `index.html` 的標記區塊；`index.html` 只讀內嵌 JSON 渲染，執行時不連網。平面「樓層導覽圖」先做、完整呈現所有內容；3D 走廊是同一份數據的另一種呈現。

**Tech Stack:** Python 3.12（只用標準函式庫；測試用 `unittest`），HTML + CSS 3D transform + 原生 JS（不用框架、不用 CDN），Playwright for Python（`channel='msedge'`）做端到端測試與截圖。

**Spec:** `SPEC.md`（v0.4）。執行者必須同時讀規格書；本計畫的每個任務都引用規格書的節號。

## Global Constraints

- 只用「同時在線人數」；月活、日活、Twitch 觀看、第三方推估都不進排名（SPEC §2）。
- 缺值一律 `null`，畫面顯示「⚠️ 待查」；整款沒有月度數據顯示「⚠️ 無月度數據」；不推估、不換算、不填 0（SPEC §2、§3.2、§10）。
- 熱度分 = 2026-01～2026-09 各月峰值平均，只算有數據的月份；至少 3 個月才有名次（SPEC §4.1）。
- 社群梗一律標「（轉述）」；頁面不得出現「【此處待作者補充」與「⚠️請核對」（SPEC §9.2、§12）。
- 不用官方 Logo、立繪、截圖、商店圖片；所有場景用 CSS 繪製（SPEC §2）。
- 配色只有：`#1C2530`、`#5B8DB8`、`#D4A24C`、`#E8E4D8`、`#C8423B`（SPEC §8）。
- 字型：`Bahnschrift, "DIN Alternate", "Roboto Condensed", "Arial Narrow"`；中文 `"Microsoft JhengHei", "PingFang TC", "Noto Sans TC"`；不載入網路字型（SPEC §8）。
- 字級只用 12、14、16、18、21、24、36、48、72 px（SPEC §8.3）。
- 時間數值：開門 0.6 秒、長按 0.6 秒、換站／轉向 0.4 秒、滑動門檻 40 px、觸控目標至少 44×44 px（SPEC §7、§11）。
- `index.html` 小於 400 KB；執行時零網路請求；`lang="zh-Hant"`（SPEC §11）。
- 房間代號：`shooter`、`rpg`、`sim`、`strategy`、`casual`、`action`（SPEC §7.10）。
- `fetch_data.py` 每個請求間隔至少 1 秒，遇到防機器人驗證就跳過，不嘗試繞過（SPEC §3.4）。
- 文字一律繁體中文；介面文案用動詞開頭、不道歉、不誇飾（SPEC §9.2）。

## Review Focus

1. **抓取時刻造成的當下人數偏差**：台灣下午抓與美國晚上抓差很多 → 留存標籤旁一定要有抓取時間；測試檢查每個留存標籤的 DOM 都有時間。（Task 6 的 `test_retention_tag_has_time`）
2. **直接打開深層網址**：`#room=action&game=gtav`、不存在的房間 `#room=xyz`、不存在的遊戲 → 前兩者到對應狀態，無效值回到重生點，不能白畫面或丟錯。（Task 9 的 `test_invalid_hash_falls_back`）
3. **窄螢幕長名稱**：「俠盜獵車手 V（傳承版＋強化版）」「Warhammer 40,000: Space Marine 2」在 375 px 不能溢出或造成橫向捲軸。（Task 10 的 `test_no_horizontal_scroll_mobile`）
4. **缺值顯示**：Fortnite 當下人數、Roblox 加總抓不到時，必須顯示「⚠️ 待查」而不是 0、`null`、`NaN` 或空白。（Task 3 的 `test_missing_now_is_null`、Task 6 的 `test_no_nan_or_null_text`）
5. **操作中途放開**：按住 E 不到 0.6 秒放開、長按中途移開手指 → 門不開、進度歸零；連按 W 快速換站不會卡在過場中間。（Task 8 的 `test_short_hold_does_not_open`、`test_rapid_moves_settle`）

```python
# tools/rules.py
"""SPEC.md 第 4、6 節的計算規則。純函式，不讀檔、不連網。"""
import datetime as dt
import math

ROOMS = [("shooter", "射擊"), ("rpg", "角色扮演"), ("sim", "模擬"),
         ("strategy", "策略"), ("casual", "休閒"), ("action", "動作冒險")]
ROOM_SLUG = {name: slug for slug, name in ROOMS}

_TAGS = {
    "射擊": ["FPS", "Shooter", "Hero Shooter", "Battle Royale", "Third-Person Shooter", "Looter Shooter", "Tactical"],
    "角色扮演": ["RPG", "Action RPG", "MMORPG", "JRPG", "Souls-like", "Hack and Slash", "Massively Multiplayer"],
    "模擬": ["Simulation", "Survival", "Open World Survival Craft", "Farming Sim", "Life Sim", "Colony Sim",
             "Driving", "Automobile Sim", "Sandbox", "Fishing"],
    "策略": ["Strategy", "MOBA", "Turn-Based Strategy", "Grand Strategy", "RTS", "Card Battler", "Deckbuilding"],
    "休閒": ["Casual", "Idler", "Relaxing", "Precision Platformer", "Music"],
    "動作冒險": ["Crime", "Action Roguelike", "Rogue-like", "Fighting", "2D Fighter", "Horror", "Survival Horror", "Hunting"],
}
TAG_ROOM = {t: room for room, ts in _TAGS.items() for t in ts}
GENERIC_TAGS = ["Action", "Adventure"]
GENRE_SKIP = {"獨立製作", "大型多人連線", "免費遊玩", "搶先體驗"}
GENRE_ROOM = {"角色扮演": "角色扮演", "模擬": "模擬", "運動": "模擬", "競速": "模擬", "策略": "策略", "休閒": "休閒"}
GENRE_LAST = {"動作": "動作冒險", "冒險": "動作冒險"}
MIN_MONTHS = 3
_MONTH_EN = ["January", "February", "March", "April", "May", "June", "July",
             "August", "September", "October", "November", "December"]


def month_keys(frm, to):
    y, m = map(int, frm.split("-"))
    ty, tm = map(int, to.split("-"))
    out = []
    while (y, m) <= (ty, tm):
        out.append((f"{y}-{m:02d}", f"{_MONTH_EN[m - 1]} {y}"))
        y, m = (y + 1, 1) if m == 12 else (y, m + 1)
    return out


def steam_monthly(chart, months):
    out = {}
    for iso, label in months:
        row = (chart or {}).get(label)
        if row and row.get("peak") is not None:
            out[iso] = int(row["peak"])
    return out


def sum_monthly(*series):
    """逐月相加；只保留每個來源都有的月份（缺一邊就不能相加）。"""
    if not series:
        return {}
    common = set(series[0]).intersection(*series[1:])
    return {k: sum(s[k] for s in series) for k in sorted(common)}


def daily_monthly(start, step, values, months):
    want = {iso for iso, _ in months}
    out = {}
    for i, v in enumerate(values):
        if v is None:
            continue
        d = dt.datetime.fromtimestamp(start + i * step, dt.timezone.utc)
        iso = f"{d.year}-{d.month:02d}"
        if iso in want:
            out[iso] = max(out.get(iso, 0), int(v))
    return out


def daily_peak_last30(values):
    vals = [v for v in values[-30:] if v is not None]
    return max(vals) if vals else None


def score(peaks):
    if not peaks:
        return None, 0
    return sum(peaks.values()) / len(peaks), len(peaks)


def status_for(months):
    if months == 0:
        return "no_monthly"
    return "ranked" if months >= MIN_MONTHS else "dark_horse"


def assign_room(key, tags, genres, overrides):
    if key in overrides:
        room, why = overrides[key]
        return room, f"人工:{why}"
    tags = tags or []
    for t in tags:
        if t in TAG_ROOM:
            return TAG_ROOM[t], f"標籤:{t}"
    for t in tags:
        if t in GENERIC_TAGS:
            return "動作冒險", f"通用標籤:{t}"
    gs = [g for g in (genres or []) if g not in GENRE_SKIP]
    for g in gs:
        if g in GENRE_ROOM:
            return GENRE_ROOM[g], f"類型:{g}"
    for g in gs:
        if g in GENRE_LAST:
            return GENRE_LAST[g], f"類型:{g}"
    return None, "無法判斷"


def retention(now, peak30):
    if now is None or not peak30:
        return None, None
    r = round(now / peak30, 2)
    tag = "退燒中" if r < 0.4 else "穩如磐石" if r > 0.85 else None
    return r, tag


def rank_games(games):
    ranked = sorted((g for g in games if g["status"] == "ranked"), key=lambda g: -g["score"])
    for g in games:
        g["rank"] = None
        g["room_rank"] = None
    room_count = {}
    for i, g in enumerate(ranked, 1):
        g["rank"] = i
        room_count[g["room"]] = room_count.get(g["room"], 0) + 1
        g["room_rank"] = room_count[g["room"]]


def room_totals(games):
    totals = {}
    for g in games:
        if g.get("room_rank") and g["room_rank"] <= 5:
            totals[g["room"]] = totals.get(g["room"], 0) + g["score"]
    return {k: round(v) for k, v in totals.items()}


def door_glow(totals):
    pos = [t for t in totals.values() if t > 0]
    if not pos:
        return {k: 0.25 for k in totals}
    lo, hi = min(pos), max(pos)
    out = {}
    for k, t in totals.items():
        if t <= 0:
            out[k] = 0.25
        elif hi == lo:
            out[k] = 1.0
        else:
            out[k] = round(0.25 + 0.75 * math.log(t / lo) / math.log(hi / lo), 4)
    return out
```

```python
# tools/fetch_data.py
"""SPEC.md 第 3.4 節：重抓所有來源。用法：python -m tools.fetch_data [--to 2026-10]"""
import argparse, datetime as dt, json, re, shutil, sys, time, urllib.error, urllib.request
from pathlib import Path

DATA = Path(__file__).resolve().parent.parent / "data"
UA = "game-heat-2026/1.0 (personal research; contact via GitHub)"
GENERATED = ["steam_top_ccu_raw.json", "top100_enriched.json", "steamcharts_monthly.json",
             "fortnitegg_1y_raw.json", "fortnitegg_now.json", "rolimons_gamelist.json",
             "fetch_log.json", "raw"]
_last = [0.0]
_ROW = re.compile(r'<td class="month-cell left[^"]*">\s*(.*?)\s*</td>.*?<td[^>]*>\s*([\d.]+)\s*</td>'
                  r'.*?</td>.*?</td>\s*<td[^>]*>\s*(\d+)\s*</td>', re.S)


def now_iso():
    return dt.datetime.now(dt.timezone(dt.timedelta(hours=8))).isoformat(timespec="seconds")


def is_bot_wall(status, body):
    b = body[:5000].lower()
    return status in (403, 429, 503) and ("just a moment" in b or "cloudflare" in b) \
        or "challenge-platform" in b or "cf-chl" in b


def get(url, headers=None, want_json=True):
    wait = 1.0 - (time.time() - _last[0])
    if wait > 0:
        time.sleep(wait)
    req = urllib.request.Request(url, headers={"User-Agent": UA, **(headers or {})})
    try:
        with urllib.request.urlopen(req, timeout=30) as r:
            status, body = r.status, r.read().decode("utf-8", "replace")
    except urllib.error.HTTPError as e:
        status, body = e.code, e.read().decode("utf-8", "replace")
    finally:
        _last[0] = time.time()
    if is_bot_wall(status, body):
        raise RuntimeError(f"防機器人驗證（HTTP {status}），依規格跳過")
    if status != 200:
        raise RuntimeError(f"HTTP {status}")
    return json.loads(body) if want_json else body


def parse_steamcharts(html):
    return {m: {"avg": float(a), "peak": int(p)} for m, a, p in _ROW.findall(html)}


def sum_rolimons(payload):
    games = payload.get("games") if isinstance(payload, dict) else None
    if not payload.get("success") or not isinstance(games, dict):
        return None
    return sum(int(v[1]) for v in games.values() if isinstance(v, list) and len(v) > 1)


def archive(data_dir, stamp):
    present = [n for n in GENERATED if (data_dir / n).exists()]
    if not present:
        return None
    dest = data_dir / "archive" / stamp
    dest.mkdir(parents=True, exist_ok=True)
    for n in present:
        shutil.move(str(data_dir / n), str(dest / n))
    return dest


def write(data_dir, name, obj):
    p = data_dir / name
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(json.dumps(obj, ensure_ascii=False, indent=1), encoding="utf-8")


def run_sources(data_dir, sources, log):
    """sources: [(id, url, fn)]；fn() 回傳 {檔名: 內容}。單一來源失敗只記錄，不中斷。"""
    for sid, url, fn in sources:
        try:
            for name, obj in fn().items():
                write(data_dir, name, obj)
            log[sid] = {"ok": True, "fetched_at": now_iso(), "error": None, "url": url}
        except Exception as e:  # noqa: BLE001 — 規格要求單一來源失敗不中斷
            log[sid] = {"ok": False, "fetched_at": now_iso(), "error": str(e), "url": url}


# ---- 各來源 ----
CCU_URL = "https://api.steampowered.com/ISteamChartsService/GetGamesByConcurrentPlayers/v1/"


def src_steam_ccu():
    return {"steam_top_ccu_raw.json": get(CCU_URL)}


def _ranks(data_dir):
    return json.loads((data_dir / "steam_top_ccu_raw.json").read_text(encoding="utf-8"))["response"]["ranks"]


def src_enriched(data_dir):
    """appdetails（tchinese，cc=tw，失敗改 cc=us）＋ SteamSpy 前 8 個標籤。"""
    out, errors = [], []
    for r in _ranks(data_dir):
        a = r["appid"]
        g = {k: r[k] for k in ("rank", "appid", "concurrent_in_game", "peak_in_game")}
        detail, tw = None, True
        for cc in ("tw", "us"):
            try:
                j = get(f"https://store.steampowered.com/api/appdetails?appids={a}&l=tchinese&cc={cc}")
                write(data_dir, f"raw/appdetails/{a}.json", j)
                if j.get(str(a), {}).get("success"):
                    detail = j[str(a)]["data"]; break
            except RuntimeError as e:
                errors.append(f"appdetails {a} cc={cc}: {e}")
            tw = False
        if detail:
            g.update(name=detail.get("name"), type=detail.get("type"),
                     genres=[x["description"] for x in detail.get("genres", [])])
            if not tw:
                g["tw_store"] = False
        try:
            spy = get(f"https://steamspy.com/api.php?request=appdetails&appid={a}")
            write(data_dir, f"raw/steamspy/{a}.json", spy)
            tags = spy.get("tags") or {}
            g["tags"] = [t for t, _ in sorted(tags.items(), key=lambda kv: -kv[1])][:8] if isinstance(tags, dict) else []
            g["name_en"] = spy.get("name") or ""
        except RuntimeError as e:
            errors.append(f"steamspy {a}: {e}")
        out.append(g)
    if errors:
        print("\n".join(errors[:20]), file=sys.stderr)
    return {"top100_enriched.json": out}


def src_steamcharts(data_dir):
    out, failed = {}, []
    for r in _ranks(data_dir):
        a = r["appid"]
        try:
            out[str(a)] = parse_steamcharts(get(f"https://steamcharts.com/app/{a}", want_json=False))
        except RuntimeError as e:
            out[str(a)] = None
            failed.append(f"{a}:{e}")
    if failed:
        print("Steamcharts 失敗：" + ", ".join(failed), file=sys.stderr)
    return {"steamcharts_monthly.json": out}


FN_HEADERS = {"Referer": "https://fortnite.gg/player-count", "X-Requested-With": "XMLHttpRequest"}


def src_fortnite_1y():
    return {"fortnitegg_1y_raw.json": get("https://fortnite.gg/player-count-graph?range=1y&id=-1", FN_HEADERS)}


def src_fortnite_now():
    """當下與 24 小時峰值：從 player-count 頁面解析。格式對不上就回傳 null（顯示待查）。"""
    html = get("https://fortnite.gg/player-count", want_json=False)
    def num(pat):
        m = re.search(pat, html, re.S | re.I)
        return int(m.group(1).replace(",", "")) if m else None
    return {"fortnitegg_now.json": {
        "now": num(r"players right now.*?([\d,]{5,})|([\d,]{5,})\s*</[^>]+>\s*<[^>]+>\s*players right now"),
        "peak_24h": num(r"24-hour peak.*?([\d,]{5,})"),
    }}


def src_rolimons():
    j = get("https://api.rolimons.com/games/v1/gamelist")
    if sum_rolimons(j) is None:
        raise RuntimeError("Rolimons 回應格式不符（沒有 success/games）")
    return {"rolimons_gamelist.json": j}


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("--to", help="計算期間最後一個月 YYYY-MM；預設上一個完整月份")
    args = ap.parse_args(argv)
    stamp = dt.datetime.now().strftime("%Y%m%d-%H%M")
    moved = archive(DATA, stamp)
    if moved:
        print(f"舊檔已移到 {moved}")
    log = {}
    run_sources(DATA, [
        ("steam_ccu", CCU_URL, src_steam_ccu),
        ("enriched", "store.steampowered.com/api/appdetails + steamspy.com", lambda: src_enriched(DATA)),
        ("steamcharts", "https://steamcharts.com/app/<appid>", lambda: src_steamcharts(DATA)),
        ("fortnitegg_1y", "https://fortnite.gg/player-count-graph?range=1y&id=-1", src_fortnite_1y),
        ("fortnitegg_now", "https://fortnite.gg/player-count", src_fortnite_now),
        ("rolimons", "https://api.rolimons.com/games/v1/gamelist", src_rolimons),
    ], log)
    today = dt.date.today().replace(day=1) - dt.timedelta(days=1)
    write(DATA, "fetch_log.json", {"run_at": now_iso(), "period_to": args.to or today.strftime("%Y-%m"),
                                   "sources": log})
    ok = [k for k, v in log.items() if v["ok"]]
    bad = {k: v["error"] for k, v in log.items() if not v["ok"]}
    print(f"成功 {len(ok)}：{', '.join(ok)}")
    for k, e in bad.items():
        print(f"失敗 {k}：{e}")
    from tools import build_data
    build_data.main(["--to", args.to] if args.to else [])


if __name__ == "__main__":
    main()
```

```python
# tools/check_copy.py
"""SPEC 9.2 的文案檢查。用法：python -m tools.check_copy"""
import json, re, sys

BANNED = ["史詩級", "神作", "必玩", "天花板", "封神", "無敵"]
PLACEHOLDERS = ["【此處待作者補充", "⚠️請核對", "⚠️ 請核對", "待查核", "〔待填〕"]
FIELDS = {"now", "peak_24h", "peak_30d", "score", "months", "rank"}
_PH = re.compile(r"\{(\w+):([\w-]+)\}")
# 允許的「數字」：遊戲名裡的數字（CS2、Dota 2、V、FC 26…）。判斷方式：把佔位符與名稱白名單移除後，不得再出現兩位以上的數字或「萬」前的數字。
_NUM = re.compile(r"\d[\d,.]*\s*(萬|億|人|%|小時|個月)")


def lint_text(where, text):
    errs = []
    for p in PLACEHOLDERS:
        if p in text:
            errs.append(f"{where}：殘留佔位符 {p}")
    for w in BANNED:
        if w in text:
            errs.append(f"{where}：誇飾詞「{w}」")
    for f, _ in _PH.findall(text):
        if f not in FIELDS:
            errs.append(f"{where}：不支援的數字欄位 {{{f}:…}}")
    if _NUM.search(_PH.sub("", text)):
        errs.append(f"{where}：手寫數字「{_NUM.search(_PH.sub('', text)).group(0)}」，請改用 {{欄位:id}}")
    return errs


def lint_game(gid, g):
    errs = []
    for k in ("intro", "why_hot", "editor_note", "source"):
        if not g.get(k):
            errs.append(f"{gid}：缺 {k}")
    if len(g.get("intro", "")) > 40:
        errs.append(f"{gid}：介紹超過 40 字")
    for m in g.get("memes", []):
        if not m.rstrip().endswith("（轉述）"):
            errs.append(f"{gid}：社群梗缺「（轉述）」")
    for k in ("intro", "why_hot", "editor_note"):
        errs += lint_text(f"{gid}.{k}", g.get(k, ""))
    for m in g.get("memes", []):
        errs += lint_text(f"{gid}.memes", m)
    return errs


def required_ids(site):
    need = set()
    for g in site["games"]:
        if (g["room_rank"] and g["room_rank"] <= 5) or (g["rank"] and g["rank"] <= 10) \
                or g["status"] in ("dark_horse", "no_monthly", "spectator", "unranked_platform"):
            need.add(g["id"])
    return need


def check(copy, site):
    errs = []
    games = copy.get("games", {})
    for gid in sorted(required_ids(site) - set(games)):
        errs.append(f"{gid}：缺文案")
    for gid, g in games.items():
        errs += lint_game(gid, g)
    for k in ("hook", "spawn_note", "spectator_quote", "pain_points", "vote", "metric_table", "rules_note", "kill_feed"):
        if k not in copy:
            errs.append(f"缺 {k}")
    errs += lint_text("hook", json.dumps(copy.get("hook", {}), ensure_ascii=False))
    ids = {g["id"] for g in site["games"]}
    for i, k in enumerate(copy.get("kill_feed", [])):
        errs += lint_text(f"kill_feed[{i}]", k.get("text", ""))
        if k.get("target") not in ids:
            errs.append(f"kill_feed[{i}]：target {k.get('target')} 不存在")
    return errs


def main():
    errs = check(json.load(open("data/copy.json", encoding="utf-8")), json.load(open("data/site_data.json", encoding="utf-8")))
    print("\n".join(errs) or "文案檢查通過")
    sys.exit(1 if errs else 0)


if __name__ == "__main__":
    main()
```

滑動轉向規則（SPEC §7.2「左滑／右滑」）：左滑＝轉向左門；面向左門時右滑＝轉回正面；面向正面時右滑＝轉向右門。`GH.scene.turn(side)` 在 `facing === side` 時轉回正面，所以：

- 左滑 → `turn(facing === "right" ? "right" : "left")`：面向右門時左滑是回正面，其餘情況是轉左。
- 右滑反之。

上面的程式就是這個邏輯。滑鼠點門仍立刻開門（SPEC §7.2），觸控只能長按。
